# Panduan Berkontribusi

Terima kasih sudah mau membantu toko-buku.

1. Fork repository ini, lalu buat branch baru dari `main`, misalnya `fitur/nama-fitur`.
2. Jalankan `python -m unittest -v` dan pastikan semua test lulus.
3. Tulis pesan commit yang singkat dan jelas.
4. Buka pull request dan jelaskan apa yang berubah.

Pull request akan dicek oleh CI sebelum di-merge.
